# Créditos visuais

A interface referencia o logotipo J&T Express em SVG hospedado no Wikimedia Commons:

- `J&T Express logo.svg`
- Fonte: Wikimedia Commons, arquivo derivado do website oficial da J&T Express.
- O logotipo é uma marca registrada e deve ser usado apenas quando você tiver autorização para isso.

A aplicação não depende do arquivo para funcionar; se a rede bloquear o Wikimedia, basta substituir a URL dos elementos `<img class="brand-logo">` por um arquivo de logo hospedado no próprio projeto.
